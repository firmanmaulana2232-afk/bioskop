Pengaturan Google Spreadsheet

Hubungkan sistem ini ke Google Sheets agar kasir di lapangan dan penjaga bioskop di kelas terhubung secara real-time.

📖 Panduan Cepat Setup Google Sheets:
  1. Buka file google-apps-script.js di folder proyek ini.
  2. Buka Google Spreadsheet baru di browser, klik menu Ekstensi > Apps Script.
  3. Paste seluruh isi script tersebut, lalu klik Terapkan (Deploy) > Deployment baru.
  4. Pilih jenis Aplikasi Web (Web app), ubah "Yang memiliki akses" jadi "Siapa saja" (Anyone).
  5. Salin URL hasil deploy (berakhiran /exec) dan tempel ke kotak di atas!
